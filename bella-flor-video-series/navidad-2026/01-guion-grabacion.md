# Guion de grabación · Navidad 2026 (para Raphet)

**Cómo grabar**

- Clóset o cuarto con cortinas, aire acondicionado y abanico apagados.
- Celular a un palmo de la boca, de lado (no de frente, para evitar soplidos). App de grabadora de voz, no video.
- Mismo cuarto y mismo celular en todas las sesiones.
- Lee cada bloque una vez completo. Si te equivocas, haz una pausa de 2 segundos y repite **la oración completa**; el editor corta.
- `/` = pausa corta · `//` = pausa larga. **Negrita** = palabra con énfasis.
- Archivo por video: `N1.m4a`, `N2.m4a`, etc.

**Tono:** canal A = cálido, pausado, como contándole algo bonito a un cliente. Canal B = suelto, con picardía, como contándole un chisme a un pana.

---

## N1 · La flor de Navidad no es una flor (canal A)

La flor más famosa de la Navidad / **no es una flor**. //
Lo rojo que tú ves son **hojas**. / Se llaman brácteas. / La flor de verdad es esto chiquitito y amarillo del centro. //
Viene de **México**. / Los aztecas le decían cuetlaxóchitl / y la usaban para tintes y medicina, / siglos antes de que fuera adorno de Navidad. //
En inglés se llama poinsettia / por Joel Poinsett, un embajador que se la llevó a Estados Unidos en el siglo diecinueve. / Aquí en Puerto Rico le decimos **pascua**, / y ya. //
Para que te llegue a **Reyes**: / mucha claridad, / lejos del chorro del aire, / y agua solo cuando la tierra esté seca. / La mayoría se muere por exceso de cariño… / y de agua. //
Regalar una pascua es regalar la Navidad entera en un tiesto. / En Bella Flor / ya llegaron.

## B1 · La pascua y la tía (canal B)

Cómo matar una pascua antes de Nochebuena, / en **tres pasos**. //
Paso uno: / el libro dice riégala solo cuando la tierra esté seca. / La tía: / le echa agua **todos los días** / “pa’ que no pase sed”. //
Paso dos: / el libro dice lejos del aire. / La tía: / la pone **debajo del split** / “pa’ que esté fresquita”. //
Paso tres: / el libro dice mucha claridad. / La tía: / la esconde en la esquina oscura / “pa’ que no se queme”. //
Resultado: / pascua ahogada, / congelada / y a oscuras / el veinte de diciembre. // Etiqueta a la tía. / **Todos tenemos una.**

## N2 · Por qué ponemos una corona en la puerta (canal A)

Esa corona que pones en la puerta / no tiene principio / ni final. / Y eso **no es casualidad**. //
El círculo es lo eterno. / Y se hace con ramas que siguen verdes en pleno invierno, / cuando todo lo demás se muere: / **vida que no se acaba**. //
Los romanos ya colgaban coronas como señal de victoria y de buena fortuna. / La Navidad tomó esa costumbre / y le dio otro significado. //
La de Adviento, con sus velas, / empezó en Alemania en el mil ochocientos: / un maestro puso velas en una rueda / para que los niños contaran los días hasta Navidad. //
En la puerta dice: / aquí se celebra, / aquí eres **bienvenido**. / Aquí en Puerto Rico, con el calor, / la hacemos con follaje que aguante, / para que te llegue a Reyes. //
Las coronas de Bella Flor / ya están en la tienda.

## N3 · El centro de mesa de Nochebuena (canal A)

El error más común en la mesa de Nochebuena: / un centro de mesa tan alto / que no ves a tu **suegra**. //
Regla uno: / **bajito**. / Que no pase de la altura de un vaso. / Si no se pueden ver las caras, no se puede hablar, / y la Nochebuena es para hablar. //
Regla dos: / nada de flores con mucho olor cerca de la comida. / El lirio es precioso, / pero compite con el **pernil**. //
Regla tres: / rojo, / verde / y textura. / Rosas rojas, hipérico, eucalipto, unas piñas. / Si quieres velas, / siempre en vaso de cristal / y lejos del follaje. //
Regla cuatro: / háztelo o búscalo **el día antes**, / y déjalo en el sitio más fresco de la casa. / Esa noche no hay tiempo para nada. //
O deja que lo hagamos nosotros. / En Bella Flor tomamos órdenes de Nochebuena hasta el **[fecha que confirme Johnny]**.

## N4 · La yerba de los camellos (canal A)

En Puerto Rico, la noche del cinco de enero, / los nenes no le dejan galletas a nadie. / Le dejan **yerba** / a unos **camellos**. //
Los Reyes Magos vienen de lejos, / y los camellos llegan con hambre. / Así que se corta yerba, / se pone en una caja / y se deja debajo de la cama. //
En la mañana, / la yerba ya no está, / y en su lugar hay regalos. / Los camellos comieron. / Los Reyes pasaron. //
Aquí la Navidad no termina el veinticinco. / Siguen los Reyes, / las Octavitas, / y hasta la San Sebastián. / Somos **la Navidad más larga del mundo**. //
Las tradiciones no se mantienen solas. / Se mantienen porque alguien sale al patio a cortar yerba. / Este año, / que lo hagan los nenes contigo.
